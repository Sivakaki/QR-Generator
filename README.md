# QR Code Generator

A modern and responsive QR Code Generator built with HTML, CSS, and JavaScript. This application allows users to instantly generate QR codes from any text or URL using a simple and intuitive interface.

## Preview

The application features:

* Clean and responsive design
* Instant QR code generation
* Support for both text and URLs
* Input validation
* Enter key support
* Modern gradient-based UI

---

## Features

- Generate QR codes from text or URLs

- Responsive design for desktop and mobile devices

- Error handling for empty input

- Generate QR codes with a button click

- Generate QR codes by pressing the Enter key

- Modern user interface with smooth hover effects

## How to Use

1. Enter any text or URL into the input field.
2. Click the **Generate QR Code** button or press **Enter**.
3. The QR code will be generated and displayed instantly.
4. Scan the QR code using a mobile device or QR scanner.

## Implementation Details

The application uses the QRServer API to generate QR codes dynamically. When a user enters text or a URL, the input is encoded and appended to the API endpoint. The generated QR code image is then displayed directly on the page.
